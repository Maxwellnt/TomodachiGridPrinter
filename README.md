
# TomodachiGridPrinter (W.I.P)

Readme work in progress

Python module to automatically print a dissing from [Living the grid](https://living-the-grid.com/) using the JSON export feature.
This project support multiple controllers projects:

* [hannahbee91/nuxbt](https://github.com/hannahbee91/nuxbt)
* [nullstalgia/UARTSwitchCon](https://github.com/nullstalgia/UARTSwitchCon)
  * This implementation is currently not working! My ESP32 overheat midway printing
* And more coming in the future

**Thanks to the Living the grid dev to implement the JSON feature.**

## Requirements

* An python 3.13 virtual environment (venv)
